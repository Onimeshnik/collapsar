Бодигруппы по умолчанию (bodygroups)

Установка конкретных бодигрупп модели при спавне (ID группы или имя -> номер бодигруппы)

🔒 Зафиксированные бодигруппы (locked_bodygroups)

Элементы, которые игрок НЕ сможет сменить в арсенале (зафиксированы уставом формы). Перечислите через запятую, например: Helmet, Chest или 0, 1

✅ Разрешенные бодигруппы (allowed_bodygroups)

Белый список: разрешено настраивать ТОЛЬКО указанные элементы (остальные заблокированы). Перечислите через запятую, например: Backpack, Pistols

⛔ Запрещенные бодигруппы (banned_bodygroups)

Черный список: элементы, которые этой профессии строго запрещено брать в арсенале. Перечислите через запятую, например: Jetpack, Cape, Pauldron

👁️ Скрытые из меню бодигруппы (hidden_bodygroups)

Элементы, которые НЕ будут отображаться в списке арсенала для этой профессии (например, чтобы убрать причёски, лица или головы). Перечислите через запятую, например: hair, fhair, head
